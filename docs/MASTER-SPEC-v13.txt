===============================================================
1. GAME NAME
===============================================================

HOTDOG DERBY

===============================================================
2. CORE GAME CONCEPT
===============================================================

Hotdog Derby is an 8-player online multiplayer horse-racing roguelike
party game.

Players are spectators who can:

- Bet on horses
- Watch races
- Throw objects at horses
- Sabotage horses
- Trade money and items
- Buy food
- Buy items
- Bid in auctions
- Buy legendary items
- Choose positive rewards
- Choose negative effects
- Obtain Upgrades
- Customize characters
- Own a personal horse
- Name their personal horse
- Customize their personal horse
- Enter their personal horse into races
- Actually control their personal horse
- Discover 48 unique normal horses
- Build different strategies
- Try to finish the run with the most money

Maximum online players:
8 HUMAN PLAYERS.

There are NO online AI player opponents.

Normal horses still use horse AI.

===============================================================
3. PLAYER COMBAT REMOVAL
===============================================================

Players DO NOT attack other players.

REMOVE:

- Punching
- Player combat
- Player damage
- Player stun
- Player knockback
- Throwing items at players as attacks

Items primarily interact with:

- Horses
- Track
- Obstacles
- Environment

- Race objects

===============================================================
7. GAME SETTING DEPENDENCIES
===============================================================

Changing settings must correctly update every dependent system.

Number of days:
- Changes total run length.
- Changes total possible daily Upgrade opportunities.

Number of races:
- Changes progression length.

Horses per race:
- Changes lanes.
- Changes starting positions.
- Changes gate slots.
- Changes odds.
- Changes payouts.
- Changes camera framing.

Number of laps:
- Changes race duration.
- Changes finish logic.

Allow Player Horses:
- Controls whether personal horses can enter.

Player Racing:
- Controls whether player-controlled races are available.

Crowd Chaos:
- Controls intensity and frequency of crowd interactions.

Prevent invalid settings combinations.

===============================================================
8. ROGUELIKE STRUCTURE
===============================================================

The MAIN MULTIPLAYER GAME is a roguelike.

The roguelike is NOT a separate mode.

As the run progresses:

- Stakes increase
- Rewards increase
- Better items become available
- Rare items appear
- More expensive purchases appear
- More unusual mechanics appear
- Risk increases

Each run should feel meaningfully different.

The goal is not pure randomness.

The player should make meaningful decisions.

- Display standings

12. UPGRADE SYSTEM
===============================================================

The old "Charm" concept is now officially called:

UPGRADES

Do NOT call these Charms in the game.

Upgrades may ONLY appear in the Positive Reward Choice.

Do NOT create:

- Upgrade Shop
- Upgrade vendor
- Upgrade inventory tab
- Upgrade equipment screen
- Upgrade equipment slots
- Upgrade purchases
- Separate Upgrade drops

The ONLY normal way to obtain an Upgrade is through the Positive Reward

===============================================================
13. DAILY UPGRADE LIMIT
===============================================================

The player gets ONE Upgrade opportunity per day.

Therefore:

3-day run = up to 3 Upgrade opportunities
5-day run = up to 5 Upgrade opportunities
10-day run = up to 10 Upgrade opportunities

Exactly ONE of the three positive reward choices should be an Upgrade.

A player should not obtain multiple daily Upgrades through the same reward
screen.

===============================================================
23. ITEM PHYSICAL CHARACTERISTICS
===============================================================

Every throwable item must have:

- Weight
- Throwing Ease
- Throw force
- Throw range
- Maximum trajectory height
- Collision behavior
- Bounce behavior where appropriate

WEIGHT:

1 = Very Light
2 = Light
3 = Medium
4 = Heavy
5 = Very Heavy

Weight primarily affects maximum throw height and vertical trajectory.

Higher weight means:

- Lower maximum attainable height
- Stronger downward arc
- Less extreme vertical throws

THROWING EASE:

1 = Very Difficult
2 = Difficult
3 = Normal
4 = Easy
5 = Very Easy

Throwing Ease primarily affects maximum horizontal throwing distance.

Higher Throwing Ease means:

- Longer possible throws
- Easier long-distance throws

Weight and Throwing Ease are SEPARATE characteristics.

===============================================================
24. HORSE EFFECT SYSTEM
===============================================================

There are exactly SIX standardized Horse Effects.

1. SPEED BOOST
2. RESISTANCE GAIN
3. STUN
4. SLOW
5. KNOCKBACK
6. INTELLIGENCE BOOST

Every horse-affecting item should use these standardized effects.

===============================================================
25. SPEED BOOST
===============================================================

Temporarily increases horse speed.

Intensity can be:

- Low
- Medium
- High
- Very High

===============================================================
26. RESISTANCE GAIN
===============================================================

Resistance Gain reduces the severity and/or duration of future negative
horse effects.

It primarily protects against:

- Stun
- Slow
- Knockback

It does NOT make the horse completely immune.

Example:

A horse with Resistance Gain gets hit by a Hotdog.

Instead of:

1.5 second stun

it might receive:

0.9 second stun

depending on resistance strength.

===============================================================
27. STUN
===============================================================

Temporarily prevents normal horse movement.

Stun is different from Slow.

Stun should temporarily interrupt the horse.

===============================================================
28. SLOW
===============================================================

Temporarily reduces horse movement speed.

Slow does not completely stop the horse.

===============================================================
29. KNOCKBACK
===============================================================

Applies physical displacement or changes the horse's racing line.

Knockback should interact with:

- Horse position
- Momentum
- Track boundaries
- Other horses
- Obstacles

===============================================================
30. INTELLIGENCE BOOST
===============================================================

Temporarily improves horse decision-making.

It can improve:

- Lane switching
- Overtaking
- Avoidance
- Reaction time
- Choosing better racing lines

===============================================================
31. ITEM EFFECT LIMIT
===============================================================

An item may have UP TO THREE different Horse Effects.

Each effect has an independent intensity.

Example:

Stun — HIGH
Slow — LOW
Knockback — LOW

Not every item needs three effects.

Some items should have only one effect.

Some should have two.

Some should have three.

The effects should have different strengths so every item does not feel the
same.

===============================================================
59. BOOMERANG RETURN SYSTEM
===============================================================

First throw:

100% return chance.

After every throw, multiply the previous return chance by:

0.75

Formula:

Return Chance =
100% × 0.75^(Throw Number - 1)

Examples:

1st throw = 100.00%
2nd throw = 75.00%
3rd throw = 56.25%
4th throw = 42.19%
5th throw = 31.64%
6th throw = 23.73%
7th throw = 17.80%
8th throw = 13.35%
9th throw = 10.01%
10th throw = 7.51%

If the return roll fails:

- Boomerang is lost.
- It does not return.
- Player must obtain another one.

One opportunity per day.

NEGATIVE EFFECT:

Chosen from two options during the reward/day progression.

PLAYER COMBAT:

REMOVED.
